### PWA Setup

A PWA (progressive web app) allows this website to be added to your home screen and behave just like an app. **Configuring the PWA is highly recommended for a better user experience.** To setup this website to act like an app, follow the instructions below:

iPhone / iPad
- Open WTTIN (this app) in Safari
- Tap the Share button
- Choose Add to Home Screen
- Tap Add

Android
- Open WTTIN (this app) in Chrome
- Tap Install app if prompted, or open the browser menu
- Choose App to Home Screen or Install app
- Confirm Install

The app will be added to the device's home screen. This can be undone at any time by selecting the app on the home screen and selecting Delete Bookmark.
